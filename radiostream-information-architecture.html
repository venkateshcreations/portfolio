09

Key Takeaways

▼

Three architectural decisions shape every other choice in RadioFlow.

Architectural decisions
  • No auth guard exists — /dj-dashboard and /admin reachable by anyone. Auth state in Zustand but no route wrapper.
  • The shell never unmounts — sidebar, AudioPlayer, ChatPanel persist across all routes.
  • Real-time is entirely client-simulated — Zustand actions shaped for future WebSocket swap.
  • Theme switching is the only persistence — Zustand → useEffect → CSS custom properties.
