01 — Overview

What GARUDA does

The UI/UX Intelligence System is a multi-agent orchestrating platform that transforms product requirements into polished, user-centered interface designs through a layered pipeline of cognitive reasoning, execution, simulation, evaluation, and memory.

05 — Pipeline Stages

Five stages, one loop

The pipeline executes in five sequential stages, exactly as defined in the markdown.

1

Cognition REASON

product-strategist → ux-psychologist → behavioral-economist → cognitive-load-analyst
2

Execution BUILD

experience-designer → interaction-architect → component-architect → ui-systems-engineer → visual-designer → copywriter-agent
3

Simulation STRESS

persona-engine → behavior-simulator → frustration-simulator → novice-user
4

Evaluation SCORE

usability-auditor → heuristic-evaluator → cognitive-friction-tester → ui-polish-agent
5

Memory LEARN

decision-recorder → pattern-learner → success-metrics

Critique Loop

if evaluation_score < 8:
    repeat execution_stage (max 3 iterations)
