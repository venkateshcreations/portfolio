01Platform Overview

StreamVerde is a cloud-native OTT/IPTV platform delivering Live TV, Video-on-Demand, Catch-Up TV, Cloud DVR, AI-powered recommendations, and full operator management through a zero-build vanilla JavaScript SPA.

Core Capabilities
📡 Streaming
Live TV, VOD, M3U/HLS playback, multi-quality (HD/Full HD/4K), DRM support (Widevine, FairPlay, PlayReady).
⏵ Time-Shifted
Catch-Up TV (7-day rewind), Cloud DVR with scheduling, EPG guide with program metadata.
🤖 Discovery
AI recommendations, search with filters, category/genre browsing, group-title channel organization.
⚙️ Management
Operator dashboard, user/subscriber CRUD, channel management, VOD library, billing/payments, analytics.
💰 Monetization
Tiered subscription plans (Basic/Pro/Ultra), ad campaigns (pre/mid/post-roll), reseller management.
🔐 Security
Role-based access (5 roles), DRM integration, encrypted streams, session management, audit-ready.

Key Architectural Decisions
#1 Zero-Build Vanilla Stack
No bundlers, no transpilers, no frameworks. Pure HTML/CSS/JS. Instant dev, zero config, maximum portability.
#2 SPA via DOM Toggle
All pages as <div class="page"> in the DOM. Router hides/shows via .active class. Zero hash or history routing.
#3 CSS Custom Props as API
Design tokens (--g4, --radius) define visual contract. All components reference variables, never raw values.
#4 Global State via window
window.App.state holds session data. Singletons on window for inline onclick compatibility.

11Do's & Don'ts

Engineering and design guidelines organized by category. Follow these to maintain consistency.

Design System
✅ Always use CSS custom properties (var(--g4)) instead of raw hex values.
❌ Don't hardcode #00ff87 or #000d07 in component styles.
✅ Use --font-display for headings only, --font-body for text, --font-mono for code/meta.
❌ Don't use Syne for body text or Manrope for stat values.
✅ Stick to the spacing scale (--space-1 through --space-12).
❌ Don't use arbitrary pixel values like 7px or 23px.
✅ Apply --radius for cards, --radius-sm for buttons/inputs.
❌ Don't mix radius sizes inconsistently.
Architecture
✅ Expose all modules on window for inline onclick compatibility.
❌ Don't use ES modules or import/export.
✅ Store session state in App.state — single source of truth.
❌ Don't scatter state across globals or DOM attributes.
✅ Use Router.goto() for all page navigation.
❌ Don't manually toggle .active classes without Router.
Roles & Access
✅ Define new roles in the ROLES config object in auth.js.
❌ Don't hardcode role checks in individual components.
✅ Use Auth._showNav(navId) to switch nav sets based on role.
❌ Don't show/hide individual nav items — swap the full set.
✅ Use toggleAdminMode() for the admin/subscriber toggle.
❌ Don't create separate login flows for toggling.
Components
✅ Use predefined CSS classes (.btn, .tag, .td-label) from components.css.
❌ Don't style interactive elements from scratch in page CSS.
✅ Use Modals.open(key) with predefined templates for dialogs.
❌ Don't build custom modals with inline HTML.
✅ Use Player.open(title) for the video player overlay.
❌ Don't create separate player implementations per content type.
Responsive
✅ Use Sidebar.toggle() for all sidebar show/hide.
❌ Don't directly toggle body.sidebar-collapsed or .sidebar.open manually.
✅ Close sidebar on mobile after navigation (Router.goto() does this).
❌ Don't leave mobile sidebar open after navigation.
✅ Use responsive grid classes for layout.
❌ Don't use fixed-width layouts that break below 768px.
Data & State
✅ Use M3U.parse() for all M3U playlist parsing.
❌ Don't write custom M3U parsers.
✅ Pass full channel object to TvPlayer.playChannel(ch).
❌ Don't pass raw URLs or partial objects.
✅ Use escapeHtml() before inserting content into DOM via innerHTML.
❌ Don't trust raw content from M3U playlists.
Navigation & Routing
✅ Add new pages as <div class="page" id="page-{id}"> in app/index.html.
❌ Don't create separate HTML files — SPA requires one file.
✅ Register page IDs in Router.PAGE_TITLES and add matching nav items.
❌ Don't use window.location or hash-based routing.
✅ Use onclick="navTo('page-id', this)" for nav click handlers.
❌ Don't use <a href> for internal navigation.
Performance
✅ Structure content so pages render with initial HTML load.
❌ Don't create DOM elements dynamically for pages.
✅ Use CSS transitions for interactive elements.
❌ Don't use JS animations if CSS transitions achieve the same effect.
✅ Destroy Hls.js via TvPlayer.destroyHls() before new streams.
❌ Don't leave old Hls.js instances running (memory leak).
Content
✅ Use placeholders that demonstrate input format.
❌ Don't use generic placeholders like “Enter text”.
✅ Show actionable messages in empty states.
❌ Don't show empty tables or blank screens.
✅ Use consistent terminology across the platform.
❌ Don't mix terms for the same feature.
Security
✅ Sanitize user input with escapeHtml() before DOM rendering.
❌ Don't use innerHTML with unsanitized content.
✅ Use role-based nav switching for UI-level access control.
❌ Don't rely solely on hiding elements.
✅ Validate M3U URLs before fetching.
❌ Don't expose internal endpoints in client code.
